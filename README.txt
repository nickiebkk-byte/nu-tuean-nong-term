เปิด index.html ด้วยเบราว์เซอร์บนคอมพิวเตอร์ หรืออัปโหลดไฟล์ทั้งโฟลเดอร์ขึ้น static hosting
หากอุปกรณ์จำกัดการเปิด HTML จากไฟล์ ให้เปิดผ่านเว็บเซิร์ฟเวอร์
ข้อมูลเก็บในเบราว์เซอร์ของเครื่องนั้น ไม่ซิงก์ข้ามเครื่อง
การแจ้งเตือนทำงานเมื่อเปิดแอป ยังไม่มี push notification
มีของใช้ ปฏิทิน เครื่องคิดเลข รายการซื้อ และสำรอง/นำเข้าข้อมูล
คูปองยังไม่ได้เชื่อมใช้งาน
ฟอนต์ Prompt โหลดผ่าน Google Fonts ต้องใช้อินเทอร์เน็ต มิฉะนั้นใช้ฟอนต์สำรอง
ภาพแมวอยู่ใน assets/cat-poses.png เป็น PNG โปร่งใส 12 ท่า เรียง 4 คอลัมน์ 3 แถว แนบไว้สำหรับนำไปใช้ ยังไม่ติดตั้งในหน้าจอแอป
ไม่มีข้อมูลส่วนตัวที่เคยบันทึกในแอปออนไลน์รวมอยู่ในไฟล์นี้ ใช้เมนูสำรองข้อมูลเพื่อนำย้ายเอง
